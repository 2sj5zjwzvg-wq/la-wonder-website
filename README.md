# L&A Wonder — анкета заказчика

Одностраничный сайт с динамическими анкетами для семи услуг студии L&A Wonder. Клиент может выбрать несколько услуг в одной заявке. Ответы отправляются в Telegram через серверный API-обработчик.

## Стек
- HTML, CSS, vanilla JavaScript
- Vercel Serverless Function (`api/submit.js`)
- Telegram Bot API
- Без внешних библиотек на сервере

## Локальный просмотр
Откройте `index.html` в браузере для просмотра дизайна и анкеты. Для реальной отправки заявок нужен серверный запуск и переменные окружения; простой просмотр HTML не подключает API.

Для локального теста с Vercel CLI:
1. Установите Node.js и Vercel CLI.
2. Выполните `vercel dev` в папке проекта.
3. Добавьте переменные `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` в локальное окружение или `.env.local`.

## Настройка Telegram
1. В Telegram откройте `@BotFather`, создайте бота командой `/newbot` и сохраните токен.
2. Напишите боту хотя бы одно сообщение. Для групп добавьте бота в нужную группу.
3. Получите chat ID с помощью подходящего Telegram-инструмента или API `getUpdates` после отправки сообщения боту.
4. Не публикуйте токен в коде браузера, репозитории или переписке.
5. В Vercel откройте **Project → Settings → Environment Variables** и добавьте:
   - `TELEGRAM_BOT_TOKEN` — токен бота
   - `TELEGRAM_CHAT_ID` — личный chat ID или ID группы
6. Сделайте redeploy после добавления переменных.

## Публикация на Vercel
1. Создайте приватный репозиторий GitHub и загрузите содержимое этой папки.
2. Импортируйте репозиторий в Vercel.
3. Добавьте две переменные окружения из раздела выше.
4. Выполните Deploy и протестируйте отправку с реальными данными.

## Что реализовано
- 7 анкет: нейрофото, мультфильм-поздравление, мультфильм с ребёнком, электронная книга, ИИ-авантюры/говорящие персонажи, кинематографический ролик, персонализированная песня.
- Общие поля ФИО, контакта, email, срока.
- Несколько услуг в одной заявке.
- Обязательные поля и проверка согласия.
- Ссылки на материалы вместо загрузки файлов.
- Honeypot-поле для базовой фильтрации автоматических отправок.
- Telegram-токен хранится только в переменных окружения серверной функции.

## Перед публичным запуском
- Укажите актуальные юридические тексты о персональных данных и согласии с учётом юрисдикции, где работает студия и где находятся клиенты.
- Проверьте фактическую настройку хранения/доступа к ссылкам, которые клиенты добавляют в анкету.
- Для публичного запуска рекомендуется добавить rate limiting, мониторинг ошибок и тесты отправки.
- В этой версии нет загрузки файлов и хранения заявок в базе данных. Если Telegram недоступен, пользователь увидит сообщение об ошибке и сможет отправить форму повторно.
- Не отправляйте токен бота клиентам и не размещайте его в `app.js`, `index.html` или других клиентских файлах.
